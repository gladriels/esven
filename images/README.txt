Drop your cover photos in this folder using these exact filenames —
the site is already wired to look for them:

  cover-hero.jpg          -> behind the big "Esven" wordmark
  cover-him.jpg            -> "For Him" tile
  cover-her.jpg             -> "For Her" tile
  cover-unisex.jpg       -> "Unisex" tile
  cover-accessories.jpg -> "Accessories" tile
  cover-places.jpg        -> "Places" tile

Any image format works if you just rename it to match (.jpg extension expected,
but .png/.jpeg will also work if you update the filename in css/style.css to match).
If a file isn't here yet, that tile just shows its plain background color instead —
nothing breaks.
